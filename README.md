# SHNK_GSN

Нормативная база для составления ЛРВ (ПТО ООО «PROBUILD GENERATION»).

- Корень — исходные сборники ШНК 4.01 / 4.02 / 4.03 / 4.04 / 4.07 / 4.09 / 4.17, архивы с дополнениями № 1–15 и ПНР.
- `_текст_и_индекс/` — текст всех сборников и дополнений (UTF-8) и `Указатель_таблиц.xlsx` (шифр таблицы → сборник → дополнения → файл и строка).
- `_правила_ЛРВ/` — регламент составления ЛРВ (`ПРАВИЛА_ЛРВ.md`) и образец файла (`Шаблон_ЛРВ_пример.xlsx`). **Читать перед каждой ЛРВ.**
