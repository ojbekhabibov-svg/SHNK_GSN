# Правила составления ЛРВ (ПТО ООО «PROBUILD GENERATION»)

Рабочий регламент, согласованный с Ойбеком (ПТО). Читать перед каждой ЛРВ.
Нормативная база — этот репозиторий: исходники в корне, текст и указатель — `_текст_и_индекс/`.

---

## 1. Порядок работы

1. **Разбор РД.** Чертежи, спецификации, ведомости, ПЗ.
2. **Проверка РД.** Сверка спецификаций с чертежами, арифметика, пропуски, противоречия между листами, отменённые нормативы.
3. **Спецификация** → **ВОР** → подбор сборников → **ЛРВ**.
4. **Самопроверка** всех позиций.
5. **Независимая проверка двумя агентами** (не видят процесса составления):
   - агент № 1 — Спецификация и ВОР против РД (объёмы, пропуски, чтение таблиц и чертежей);
   - агент № 2 — нормы против ШНК (таблица, вариант, коэффициенты ТЧ, дополнения, формат шифров).
6. **Сведение замечаний** — спорное перепроверяется по первоисточнику.
7. **Выдача:** ЛРВ + лист «Проверка» (что проверено / исправлено / осталось допущением).

Проверка выполняется для **любой** ЛРВ, независимо от размера. Время — не ограничение, нужна максимальная правильность.
Для больших объектов: сначала Спецификация и ВОР на согласование, затем ЛРВ.

## 2. Правила по РД и объёмам

- Ведомость ≠ чертёж → **приоритет у чертежа**; расхождение — замечанием в ВОР и в колонке I ЛРВ.
- Иные расхождения между источниками → принят **больший** объём, с указанием источника.
- Объёмы, которых нет в ВОР, но есть на чертежах (котлованы, подушки, проезды и т.п.) — считать по чертежу, отметить замечанием к РД.
- Работы не из ВОР (уплотнение, полив и т.п.) — **только если** заложены в проектной документации или прямо требуются нормами/ТЧ. Аналогия с другими объектами — не основание.
- Цифру в РД не считать опечаткой самовольно — принять как есть, вынести в замечания.
- Таблицы РД читать построчно (пример ошибки: 3 водопропускные трубы 10+13+13 м, а не 3×10).
- Графы спецификаций (металл по группам и т.п.) сверять внимательно.
- Группа грунта — по ИГЭ или прямому указанию в ВОР; сейсмическую категорию не путать с группой разработки.
- Дальность вывоза грунта не указана → **5 км** (отметить в примечании; корректируется вручную).
- Объём для нормы — в её измерителе (блок-контейнеры — по объёму блоков, не строительный объём здания).

## 3. Правила по нормам (ШНК)

- Шифры норм и коды ресурсов — **точно как в источнике**, из которого взята норма (4.02.01: «01-01-013-8»; Доп. № 6: «01-01-014-01»; 4.02.25: «25-10-001-05»).
- Перед применением аналога — искать прямую норму в дополнениях № 1–15 (лист «Таблицы в дополнениях» указателя). Применять последнюю редакцию, источник указывать.
- Каждый коэффициент — со ссылкой на пункт ТЧ, иначе не применять.
- Вариант нормы — по фактическому параметру; при промежуточном значении — ближайший больший.
- Серии 4.02 (строительные) и 4.17 (монтаж) имеют совпадающие шифры — проверять серию.
- Изготовление МК и армокаркасов (сб.38, 06-02-011) — отдельной нормой, **если** в норме монтажа/бетонирования изготовление не учтено. Сталь — учитывать один раз.
- Сопутствующие работы: обработка плёнок РК (25-05-030), продувка (12-19-011) при требовании РД, перевозка грунта, работа бульдозера на отвале, монтаж оборудования (а не только поставка).
- ПНР — только если заложены в РД; по ГЭСНп из `ПНР.rar` (с «Указаниями по применению»).

### Проверенные по ТЧ положения ШНК 4.17.12-04
- Длина трубопровода (ТЧ п.11): по трассе с фасонными деталями, **без** строительной длины арматуры.
- Каждая линия — по прокладке и давлению: подземная/межцеховая — отдел 02 (12-02-…), цеховая/надземная — отдел 01 (12-01-…); Ру ≤ 2,5 МПа — 12-01-004 / 12-02-006, Ру ≤ 10 МПа — 12-01-005 / 12-02-007.
- Площадочная обвязка — сб.12, не сб.25 (магистральные). К=1,125 «на трассе» сб.25 к площадке не применять.
- Установка опор учтена в нормах **отделов 01 и 19**; в отделе 02 — не указана (отдельный монтаж опор для 12-01 — двойной учёт).
- Отдел 12 п.2: К=1,15 (пневмо-/гидропривод), К=1,1 (червячная передача) — **кроме таблиц 12-12-003, 004, 007, 008** (нормы на электропривод).
- 12-12-020 / 12-12-021 — краны со смазкой бесколодезной установки (6,4 / 8 МПа), измеритель 10 шт.
- Отдел 19 п.6: очистка воздухом и испытания — дополнительно по 12-19-011, 12-19-009, 12-19-010.

### ШНК 4.02.01-04
- ТЧ п.3.187: доработка вручную после механизированной разработки — К=1,2 (табл. 02-055…02-058).

## 4. Цены (лист «Ресурсы»)

Источник цен — репозиторий [resource-prices](https://github.com/ojbekhabibov-svg/resource-prices), файлы в `прайсы/` (реестр — `прайсы/README.md`). Сводная база не ведётся.

- **Основное правило: брать максимальную (самую высокую) из найденных сопоставимых цен** по всем файлам; без НДС, в сумах, в одной единице. Цена, выбивающаяся более чем в 2 раза, — применяется с отметкой для проверки.
- Сопоставление по смыслу, с учётом характеристик (грузоподъёмность, мощность, диаметр и т.д.).
- Разные единицы — пересчитывать логически (электроды 15 000 000 сум/Т → 15 000 сум/КГ); пересчёт через массу/плотность — с указанием основания.
- Источник цены — кратко в колонке F: «IV кв. 2026г. г. Ташкент».
- Цены нет — ячейку цены **оставить пустой**.
- **Людские ресурсы — одна цена для всех категорий рабочих** (затраты труда рабочих-строителей, рабочих-монтажников, доп. перемещение рабочих-строителей по трассе и прочие): единая ставка чел-ч, по общему правилу — максимальная из найденных. Затраты труда машинистов и доп. перемещение машинистов — 0 сум (учтены в стоимости маш-ч). Ставка чел-ч может браться из таблицы среднечасовой зарплаты (`resource-prices/прайсы/зарплата/`); графа (без соцстраха / с соцстрахом 12 %) и регион решаются **по ситуации** — уточнять у Ойбека при каждой ЛРВ.

## 5. Формат файла

Один файл на объект: **Реестр** → **Ресурсы** (общие) → **Спецификация** → **ВОР** → **ЛРВ-<дисциплина>** (по одной на дисциплину).
Образец — `Шаблон_ЛРВ_пример.xlsx` в этой папке.

### Ресурсы
A ключ =C&D (скрыт) · B тип («обор.», «каб.», «мз», иначе пусто) · C наименование (ПРОПИСНЫМИ) · D ед. изм. (ЧЕЛ-Ч, МАШ-Ч, Т, ШТ, М3) · E цена (=I×J, #,##0) · F источник цены · G–L (сгруппированы): позиция в прайсе, ед. прайса, цена прайса, коэф. пересчёта, основание, статус (зелёный — точно, жёлтый — проверить, красный — нет цены).
Шапка Calibri 9 bold, заливка CCFFFF; C/D Calibri 10.

### Спецификация / ВОР
- Спецификация: № / Наименование и техническая характеристика / Ед. изм. / Кол-во / Раздел / Примечание.
- ВОР: № / Наименование работ / Ед. изм. / Кол-во / Шифр норматива / Примечание (источник объёма; при расхождении — какой принят) + общие примечания + перечень «Замечания к РД».
- Дисциплины разделены тёмно-синими строками, разделы — голубыми. Поштучно (фасонные детали, ж/б элементы, металл по сортаменту), без % потерь.
- Замечания к РД — «⚠ Замечание № N к РД: …», ячейка оранжевая.

### ЛРВ
- Шапка строки 1–3: A «N п.п.», B «Шифр номера нормативов и коды ресурсов», C «Наименование работ и затрат», D «Единица измерения», E:F «Количество» (на ед. изм. / по проектным данным), G:H «Стоимость» (Стоимость за ед. / СУММА), I «Примечание»; строка 3 — номера; Times New Roman Cyr 9, CCFFFF, тонкие границы; ширины B≈18, C≈82, G/H≈16.
- Раздел: «РАЗДЕЛ N. …», A:F объединены, TNR Cyr 12 bold, CCFFFF.
- Работа: TNR Cyr 10 bold; виды работ **ПРОПИСНЫМИ**; объём в E — ссылкой на ВОР.
- Ресурсы: TNR Cyr 9; A «N.M» текстом; цвет: ЧЕЛ-Ч 800080, МАШ-Ч 003300, материалы 000080; E норма; F =+E*$E$<строка работы>; G =+VLOOKUP(C&D;Ресурсы!A:E;5;0); H =+F*G.
- «Затраты труда машинистов» — строкой ЧЕЛ-Ч по 0 сум.
- Оборудование / кабель / материалы заказчика — отдельные строки: тип в B, «Ф» в E, кол-во в F (ссылкой на Спецификацию).
- Примечания (замечания к РД, допущения) — колонка **I**.
- **Границы: тонкие границы у всех ячеек A–I по всей таблице** — шапка, разделы, работы, ресурсы, строки «Ф», пустые строки-разделители и весь итоговый блок. Перед выдачей проверить, что ни одна строка не осталась без границ.
- Итоговый блок: ВСЕГО ЗАТРАТ; Сзп; Сэм; Коэф. на стеснённые условия (0%); См; Кабельная продукция; Трансп. на материалы 5%; Трансп. на кабель 1,5%; ЗСР 2%; ИТОГО; ОБОРУДОВАНИЕ; Трансп. на оборудование 2%; Прочие затраты и расходы Подрядчика **17%**; ИТОГО; НДС 12%; МИНУС МАТЕРИАЛЫ ЗАКАЗЧИКА; ВСЕГО СТОИМОСТЬ СТРОИТЕЛЬСТВА В ТЕКУЩИХ ЦЕНАХ (с НДС 12%).

### Реестр
№ / Марка РД / Дисциплина / Наименование ЛРВ / Итого без НДС / НДС 12% / Материалы заказчика / Всего с НДС / Замечаний к РД / Примечание; суммы — формулами из итогов ЛРВ.

## 6. Журнал уроков (ошибки прошлых ЛРВ)

| Ошибка | Правильно |
|---|---|
| DN1200 обвязки по сб.25 «приведённо» по стыкам | сб.12, 12-02-007 |
| К=1,15 к 12-12-008 | запрещено ТЧ отд.12 п.2 |
| Подземные участки по надземным нормам; давление 1,6 МПа по нормам 10 МПа | разделять по прокладке и давлению |
| Длины труб без фасонных деталей / с арматурой | ТЧ п.11 |
| Изоляция малых Ду «приведена» к Ду300 | 25-07-017 (Доп. № 6) |
| Пескоструйка 13-06-002-01 без поправки | состав по Доп. № 3 |
| Пропуск обработки плёнок РК, продувки, перевозки грунта, полива | см. п.3 |
| Двойной учёт стали (изготовление + «конструкции стальные» в монтаже) | сталь один раз |
| Перепутаны графы металлокаркаса | сверять графы спецификации |
| Водопропуски 3×10 м вместо 10+13+13 | читать таблицу построчно |
| Контейнеры по строительному объёму 560 м3 | по объёму блоков |
| Котлован и подушка ГПС не учтены (нет в ВОР) | считать по чертежу + замечание |
| Шифры «-01» там, где в сборнике «-1» | как в источнике |
| Итоговый блок ЛРВ без границ | границы у всех ячеек A–I по всей таблице |
| Прочие затраты 17,27% | с 21.10.2026 — 17% |

Дополнять журнал после каждой проверки.
