# Правила составления ЛРВ (ПТО ООО «PROBUILD GENERATION»)

Рабочий регламент, согласованный с Ойбеком (ПТО). Читать перед каждой ЛРВ.
Нормативная база — этот репозиторий: исходники в корне, текст и указатель — `_текст_и_индекс/`.

---

## 1. Порядок работы

### 1.1 Схема «3 + 1» (с 26.11.2026, заменяет проверку двумя агентами)
ЛРВ формируют **три независимых агента-составителя** (А1, А2, А3), **четвёртый агент-сводчик** (А4) собирает из них единую ЛРВ. Цель — минимизировать ошибки: расхождение между тремя независимыми расчётами указывает на ошибку.

**Агенты А1, А2, А3** — каждый по стандартной хронологии, полностью самостоятельно:
1. Разбор и проверка РД (сверка спецификаций с чертежами, арифметика, пропуски, противоречия, все листы PDF по штампу).
2. **Спецификация** → 3. **ВОР** → 4. подбор сборников → 5. **ЛРВ** (с ценами по разделу 4) → 6. самопроверка.

Независимость: одинаковое задание (РД + этот регламент + шаблон); агенты **не видят** работы друг друга и результатов сводчика. Каждый сохраняет свой файл отдельно (ЛРВ_А1 / ЛРВ_А2 / ЛРВ_А3) и перечень своих замечаний к РД и допущений.

**Агент А4 (сводчик)** — сравнивает три результата **позиция за позицией**: состав работ и позиций Спецификации, физические объёмы, материалы и количества, шифры норм и варианты, коэффициенты, коды и нормы расхода ресурсов, цены и их источники, замечания к РД.
- **Совпадение:** штучные позиции (шт, комплект, переход и т.п.) — точно; прочие — после округления до точности ВОР/ЛРВ (как значение выводится в ведомости).
- Все три агента дали **одинаковое** значение → принимается без дополнительной проверки (проверка А4 не обязательна).
- Есть **расхождение** (например, 1000 / 1000 / 950 м3) или позиция есть не у всех → А4 **лично** выясняет причину по первоисточнику (РД, текст ШНК, ТЧ, дополнения, прайс) и принимает правильное значение. Большинство голосов основанием не является: «2 из 3» тоже проверяется.
- **Неоднозначность РД** (А4 по первоисточнику не может установить единственно верное значение — РД допускает два прочтения) → принимается **больший** объём, оформляется ⚠ замечание к РД, вопрос выносится Ойбеку; то же — в колонке I ЛРВ у позиции.
- Замечания к РД — объединяются (замечание, найденное хотя бы одним агентом, проверяется и при подтверждении включается).
- А4 собирает единую ЛРВ (Реестр, Ресурсы, Спецификация, ВОР, ЛРВ-<дисциплина>) по шаблону и правилам раздела 5.

**Выдача:** единая ЛРВ + лист «Проверка» — таблица расхождений: № (Р-N) / лист / позиция / параметр / А1 / А2 / А3 / принято / причина расхождения и источник / вид. Позиции без расхождений в лист не выносятся (указывается их количество). Каждое расхождение **дублируется в колонке I** листа ЛРВ у своей позиции: «◆ Расхождение Р-N (лист «Проверка»): А1 … / А2 … / А3 …; принято …» (знак ◆, не ⚠ — ⚠ зарезервирован за замечаниями к РД и считается в Реестре).

### 1.3 Хранение
- **Рабочие файлы** (РД, результаты А1–А3, черновики) — локальная папка `E:\PBG\LRV` (когда Claude Code работает на компьютере Ойбека); в облачной сессии — рабочая папка сессии (временная).
- **Финальные ЛРВ** — репозиторий [LRV](https://github.com/ojbekhabibov-svg/LRV): папка на объект, в ней итоговый файл ЛРВ (с листом «Проверка»). Выкладывать только финальные версии.

Схема применяется к **любой** ЛРВ, независимо от размера. Время — не ограничение, нужна максимальная правильность.

### 1.2 Большие объекты
Сначала Спецификация и ВОР — три агента + сводка А4 — на согласование Ойбеку; после согласования — ЛРВ по той же схеме «3 + 1» на основе согласованных Спецификации и ВОР.

## 2. Правила по РД и объёмам

- Ведомость ≠ чертёж → **приоритет у чертежа**; расхождение — замечанием в ВОР и в колонке I ЛРВ.
- Иные расхождения между источниками → принят **больший** объём, с указанием источника.
- Объёмы, которых нет в ВОР, но есть на чертежах (котлованы, подушки, проезды и т.п.) — считать по чертежу, отметить замечанием к РД.
- Работы не из ВОР (уплотнение, полив и т.п.) — **только если** заложены в проектной документации или прямо требуются нормами/ТЧ. Аналогия с другими объектами — не основание.
- Цифру в РД не считать опечаткой самовольно — принять как есть, вынести в замечания.
- Таблицы РД читать построчно (пример ошибки: 3 водопропускные трубы 10+13+13 м, а не 3×10).
- Графы спецификаций (металл по группам и т.п.) сверять внимательно.
- Группа грунта — по ИГЭ или прямому указанию в ВОР; сейсмическую категорию не путать с группой разработки.
- Дальность вывоза грунта не указана → **5 км** (отметить в примечании; корректируется вручную).
- Объём для нормы — в её измерителе (блок-контейнеры — по объёму блоков, не строительный объём здания).

## 3. Правила по нормам (ШНК)

- Шифры норм и коды ресурсов — **точно как в источнике**, из которого взята норма (4.02.01: «01-01-013-8»; Доп. № 6: «01-01-014-01»; 4.02.25: «25-10-001-05»).
- Перед применением аналога — искать прямую норму в дополнениях № 1–15 (лист «Таблицы в дополнениях» указателя). Применять последнюю редакцию, источник указывать.
- Каждый коэффициент — со ссылкой на пункт ТЧ, иначе не применять.
- Вариант нормы — по фактическому параметру; при промежуточном значении — ближайший больший.
- Серии 4.02 (строительные) и 4.17 (монтаж) имеют совпадающие шифры — проверять серию.
- Изготовление МК и армокаркасов (сб.38, 06-02-011) — отдельной нормой, **если** в норме монтажа/бетонирования изготовление не учтено. Сталь — учитывать один раз.
- Сопутствующие работы: обработка плёнок РК (25-05-030), продувка (12-19-011) при требовании РД, перевозка грунта, работа бульдозера на отвале, монтаж оборудования (а не только поставка).
- ПНР — только если заложены в РД; по ГЭСНп из `ПНР.rar` (с «Указаниями по применению»).

### Проверенные по ТЧ положения ШНК 4.17.12-04
- Длина трубопровода (ТЧ п.11): по трассе с фасонными деталями, **без** строительной длины арматуры.
- Каждая линия — по прокладке и давлению: подземная/межцеховая — отдел 02 (12-02-…), цеховая/надземная — отдел 01 (12-01-…); Ру ≤ 2,5 МПа — 12-01-004 / 12-02-006, Ру ≤ 10 МПа — 12-01-005 / 12-02-007.
- Площадочная обвязка — сб.12, не сб.25 (магистральные). К=1,125 «на трассе» сб.25 к площадке не применять.
- Установка опор учтена в нормах **отделов 01 и 19**; в отделе 02 — не указана (отдельный монтаж опор для 12-01 — двойной учёт).
- Отдел 12 п.2: К=1,15 (пневмо-/гидропривод), К=1,1 (червячная передача) — **кроме таблиц 12-12-003, 004, 007, 008** (нормы на электропривод).
- 12-12-020 / 12-12-021 — краны со смазкой бесколодезной установки (6,4 / 8 МПа), измеритель 10 шт.
- Отдел 19 п.6: очистка воздухом и испытания — дополнительно по 12-19-011, 12-19-009, 12-19-010.

## 4. Цены (лист «Ресурсы»)

### 4.1 Запрос перед ЛРВ
Перед началом каждой ЛРВ (до запуска агентов А1–А3) — запрос Ойбеку:

> **Цены в ЛРВ**
> 1. Проставлять цены в лист «Ресурсы»? — да / нет
> 2. Если да — откуда брать: отдельный файл (пришлёт Ойбек) / репозиторий resource-prices / оба
> 3. Ставка чел-ч: графа (без соцстраха / с соцстрахом 12 %) и регион

- **Нет** → ЛРВ без цен: лист «Ресурсы» заполняется полностью (тип, наименование, ед. изм.), цены (E) и колонки сопоставления G–L — пустые; формулы VLOOKUP и итогового блока сохраняются (дают 0 до заполнения цен).
- **Да** → цены по выбранному источнику с правилами 4.3, проверка — по 4.2. Если источник — файл Ойбека, сопоставление и пересчёт по тем же правилам; источник в колонке F — по данным этого файла.
- **Оба** → максимальная из сопоставимых цен по файлу Ойбека и resource-prices.
- Ответ один на всю ЛРВ: все агенты А1–А3 работают от одного источника цен.

### 4.2 Проверка цен — по схеме «3 + 1»
- Цены подбирают **независимо** все три агента А1–А3 (из одного источника по ответу на 4.1): для каждого ресурса — позиция в прайсе, ед. прайса, цена прайса, коэф. пересчёта, итоговая цена, источник.
- А4 сравнивает по каждому ресурсу: выбранную позицию прайса (сопоставление по смыслу и характеристикам), единицу и коэф. пересчёта, итоговую цену.
- Совпало у всех трёх → принимается. Расхождение (разные позиции, разный пересчёт, у кого-то цены нет, разные цены) → А4 лично проверяет по прайсу. «2 из 3» основанием не является.
- Если один из агентов нашёл **более высокую** сопоставимую цену — А4 проверяет сопоставимость и при подтверждении принимает её (правило максимальной цены).
- Расхождения по ценам — в лист «Проверка» (ресурс / цена А1 / А2 / А3 / принято / причина и источник).
- Та же схема — если цены проставляются позже в ЛРВ, выданную без цен.

### 4.3 Правила цен
Репозиторий [resource-prices](https://github.com/ojbekhabibov-svg/resource-prices) — файлы в `прайсы/` (реестр — `прайсы/README.md`). Сводная база не ведётся.

- **Основное правило: брать максимальную (самую высокую) из найденных сопоставимых цен** по всем файлам; без НДС, в сумах, в одной единице. Цена, выбивающаяся более чем в 2 раза, — применяется с отметкой для проверки.
- Сопоставление по смыслу, с учётом характеристик (грузоподъёмность, мощность, диаметр и т.д.).
- Разные единицы — пересчитывать логически (электроды 15 000 000 сум/Т → 15 000 сум/КГ); пересчёт через массу/плотность — с указанием основания.
- Источник цены — кратко в колонке F: «IV кв. 2026г. г. Ташкент».
- Цены нет — ячейку цены **оставить пустой**.
- **Людские ресурсы — одна цена для всех категорий рабочих** (затраты труда рабочих-строителей, рабочих-монтажников, доп. перемещение рабочих-строителей по трассе и прочие): единая ставка чел-ч, по общему правилу — максимальная из найденных. Затраты труда машинистов и доп. перемещение машинистов — 0 сум (учтены в стоимости маш-ч). Ставка чел-ч может браться из таблицы среднечасовой зарплаты (`resource-prices/прайсы/зарплата/`); графа (без соцстраха / с соцстрахом 12 %) и регион решаются **по ситуации** — уточнять у Ойбека при каждой ЛРВ (запрос 4.1, п. 3).

## 5. Формат файла

Один файл на объект: **Реестр** → **Ресурсы** (общие) → **Спецификация** → **ВОР** → **ЛРВ-<дисциплина>** (по одной на дисциплину).
Образец — `Шаблон_ЛРВ_пример.xlsx` в этой папке (**финальный шаблон**). Лист «Проверка» — последним.

### Ресурсы
A ключ =C&D (скрыт) · B тип («обор.», «каб.», «мз», иначе пусто) · C наименование (ПРОПИСНЫМИ) · D ед. изм. (ЧЕЛ-Ч, МАШ-Ч, Т, ШТ, М3) · E цена (=I×J, #,##0) · F источник цены · G–L (сгруппированы): позиция в прайсе, ед. прайса, цена прайса, коэф. пересчёта, основание, статус (зелёный — точно, жёлтый — проверить, красный — нет цены).
Шапка Calibri 9 bold, заливка CCFFFF; C/D Calibri 10.

### Спецификация / ВОР
- Спецификация: № / Наименование и техническая характеристика / Ед. изм. / Кол-во / Раздел / Примечание.
- ВОР: № / Наименование работ / Ед. изм. / Кол-во / Шифр норматива / Примечание (источник объёма; при расхождении — какой принят) + общие примечания + перечень «Замечания к РД».
- Дисциплины разделены тёмно-синими строками, разделы — голубыми. Поштучно (фасонные детали, ж/б элементы, металл по сортаменту), без % потерь.
- Замечания к РД — «⚠ Замечание № N к РД: …», ячейка оранжевая.

### ЛРВ
- Шапка строки 1–3: A «N п.п.», B «Шифр номера нормативов и коды ресурсов», C «Наименование работ и затрат», D «Единица измерения», E:F «Количество» (на ед. изм. / по проектным данным), G:H «Стоимость» (Стоимость за ед. / СУММА), I «Примечание»; строка 3 — номера; Times New Roman Cyr 9, CCFFFF, тонкие границы; ширины B≈18, C≈82, G/H≈16.
- Раздел: «РАЗДЕЛ N. …», A:F объединены, TNR Cyr 12 bold, CCFFFF.
- Работа: TNR Cyr 10 bold; виды работ **ПРОПИСНЫМИ**; объём в E — ссылкой на ВОР.
- Ресурсы: TNR Cyr 9; A «N.M» текстом; цвет: ЧЕЛ-Ч 800080, МАШ-Ч 003300, материалы 000080; E норма; F =+E*$E$<строка работы>; G =+VLOOKUP(C&D;Ресурсы!A:E;5;0); H =+F*G.
- «Затраты труда машинистов» — строкой ЧЕЛ-Ч по 0 сум.
- Оборудование / кабель / материалы заказчика — отдельные строки: тип в B, «Ф» в E, кол-во в F (ссылкой на Спецификацию).
- Примечания (замечания к РД «⚠», расхождения агентов «◆ Р-N», допущения) — колонка **I**; TNR Cyr 9, перенос текста, по верху.
- **Границы: тонкие границы у всех ячеек A–I по всей таблице** — шапка, разделы, работы, ресурсы, строки «Ф», пустые строки-разделители и весь итоговый блок. Перед выдачей проверить, что ни одна строка не осталась без границ.
- Итоговый блок: ВСЕГО ЗАТРАТ; Сзп; Сэм; Коэф. на стеснённые условия (0%); См; Кабельная продукция; Трансп. на материалы 5%; Трансп. на кабель 1,5%; ЗСР 2%; ИТОГО; ОБОРУДОВАНИЕ; Трансп. на оборудование 2%; Прочие затраты и расходы Подрядчика **17%**; ИТОГО; НДС 12%; МИНУС МАТЕРИАЛЫ ЗАКАЗЧИКА; ВСЕГО СТОИМОСТЬ СТРОИТЕЛЬСТВА В ТЕКУЩИХ ЦЕНАХ (с НДС 12%).

### Реестр
№ / Марка РД / Дисциплина / Наименование ЛРВ / Итого без НДС / НДС 12% / Материалы заказчика / Всего с НДС / Замечаний к РД / Примечание; суммы — формулами из итогов ЛРВ.

## 7. Изменение правил

Если при составлении ЛРВ выявлена поправка к процессу (новая ошибка, неучтённый случай, иной порядок, уточнение нормы или цены) — Claude **не меняет регламент молча**, а направляет Ойбеку запрос:

> **Запрос на изменение правил № N**
> Что выявлено: … (объект, позиция, источник)
> Предлагаемое правило: … (формулировка)
> Куда: раздел … ПРАВИЛА_ЛРВ.md / журнал уроков
> Применять к дальнейшим ЛРВ? — да / нет / с правкой

- **Да** → правило вносится в этот файл (и в журнал уроков), запись в ЛОГ_СЕССИИ.md, коммит.
- **Нет** → в правила не вносится; при необходимости — отметка в ЛОГ_СЕССИИ.md, чтобы не предлагать повторно.
- Текущая ЛРВ исправляется по существу сразу; готовые (выданные) ЛРВ задним числом не меняются, если Ойбек не скажет иное.
- Запросы собираются по ходу работы и выдаются вместе с ЛРВ (или сразу, если влияют на дальнейший расчёт).
