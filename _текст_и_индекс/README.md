# Текст и указатель таблиц норм

Служебная папка для быстрого и надёжного поиска норм при составлении ЛРВ. Исходные файлы в корне репозитория не изменялись.

## Состав
- `текст/` — все сборники, дополнения № 1–15, ПНР и технические части в виде текста UTF-8 (архивы распакованы; структура папок как в источнике).
- `Указатель_таблиц.xlsx` — указатель таблиц норм: серия, шифр таблицы, наименование, измеритель, количество норм, пример шифра нормы, источник, наличие в дополнениях, файл и строка.
- `указатель_таблиц.csv` — то же в CSV (разделитель «;»).

## Объём
- Исходных файлов: 157, все прочитаны (статусы — лист «Файлы»).
- Найдено таблиц норм: 7933, из них в дополнениях: 1549; ПНР: 689.
- Серия не определена автоматически: 34 строк дополнений (отмечены розовым).

## Правила
1. Шифр нормы — как в источнике, из которого взята норма.
2. Если таблица есть в дополнении — применять последнюю редакцию и указывать источник.
3. Серии 4.02 (строительные) и 4.17 (монтаж) имеют совпадающие шифры — проверять колонку «Серия».
